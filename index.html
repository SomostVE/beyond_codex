Beyond Codex

Structured Shadowverse: Worlds Beyond card data for Beyond Decks and other tools.

Beyond Codex snapshots and normalizes the official English card database so applications can consume stable JSON endpoints instead of repeatedly querying the official Deck Portal.

  "https://somostve.github.io/beyond_codex/api/v1/cards.json"
);

curl

curl https://somostve.github.io/beyond_codex/api/v1/cards.json

API v1 endpoints

  • api/v1/cards.json — complete normalized card database, including tokens and generated cards.
  • api/v1/metadata.json — sets, traits, keywords, source information and generation metadata.
  • api/v1/changelog.json — cards added, modified or removed since the previous snapshot.
  • api/v1/manifest.json — schema version, generation timestamp, counts and endpoint list.
  • api/v1/classes/*.json — smaller datasets split by class.

Card object

Every item in cards.json is a normalized card object. Useful fields include:

  • id, baseCardId, name
  • class, setId, set, type, rarity
  • cost, attack, defense, maxCopies
  • traits, keywords
  • text for cleaned card text and rawSkillText for the original formatted skill text
  • rotation, token, relatedCards
  • image, imageHash, evolved, styles
  • newlyAdded and modifiedInLatestUpdate for update tracking

Filtering examples

Find one card by ID

const card = cards.find(card => card.id === 10101110);

Only deck-selectable Runecraft cards

const runecraft = cards.filter(card =>
  card.class === "Runecraft" &&
  !card.token &&
  card.maxCopies > 0
);

Find cards with Fanfare

const fanfareCards = cards.filter(card =>
  /\bFanfare\s*:/i.test(card.text)
);

Versioning and updates

v1 is the API schema version, not the card database version. Weekly card additions and balance/text changes update the existing /api/v1/ snapshot. A future /api/v2/ would only be introduced for an incompatible schema change.

The dataset refreshes automatically every Monday at 04:20 UTC. A manual GitHub Actions refresh is also available for releases or emergency updates.

Use manifest.json to read the current schemaVersion, generatedAt timestamp and card counts. Use changelog.json to detect what changed between snapshots.
